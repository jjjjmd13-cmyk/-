# Combat visual polish: source assets and generation prompts

All four assets were created with the built-in `image_gen.imagegen` tool, not an external API or CLI. The generated PNGs themselves are the production source assets: no painted detail was synthesized with code. Requested dimensions were 2048 square; the tool returned 1254 × 1254 for each. Atlas cells therefore use floating-point regions (313.5 px for 4×4, 627 px for 2×2), with `AtlasTexture.filter_clip` enabled. No resizing or destructive image processing was used. The props PNG retains the generated RGBA alpha; VFX deliberately retain black for additive blending.

| Asset | File | Layout |
|---|---|---|
| Courtyard floor | `assets/environment/courtyard-floor.png` | One material, mirrored neighbouring tiles to match edge texels |
| Environment props | `assets/environment/courtyard-props.png` | 2×2: pillar, broken pillar, brazier, statue |
| Ability icons | `assets/ui/ability-icons.png` | 4×4: knight, ranger, mage, rogue rows; skill, skill2, ultimate, dash columns |
| Additive effects | `assets/vfx/ability-effects.png` | 4×4: same hero rows; seal, slash, impact, signature effect columns |

This is a production texture consumed directly by the game. Polished high resolution material.
