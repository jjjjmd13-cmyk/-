# 레벨업 카드 정리

`docs` 폴더의 "스킬과 레벨업 선택 개선안(2026-10-24)"을 반영한 카드 시스템입니다.
카드 데이터는 `scripts/data/upgrades.gd`, 효과는 `scripts/game/player.gd`에 있습니다.

## 레벨업 흐름

- **짝수 레벨과 5의 배수 레벨**에만 카드 선택 창이 뜹니다(한 판에 약 15~20번).
- 나머지 레벨은 작은 강화가 **자동으로 적용**되고, 캐릭터 위에 글자로 표시됩니다.
  - 공격력 +4%, 공격 속도 +4%, 최대 체력 +12, 이동 속도 +3%, 치명타 확률 +2% 중 하나
- **5레벨마다** 희귀 이상 카드가 최소 1장 나옵니다.
- 웨이브 **5·10 보스**를 잡으면 **보스 보상** 창이 떠서 전설 카드 1장을 고릅니다.
- 판마다 **다시 뽑기 3번**, **제외 2번**을 쓸 수 있습니다.
  - 다시 뽑기 `R`: 지금 카드 3장을 새로 뽑습니다.
  - 제외 `X`: 제외 모드를 켠 뒤 카드를 고르면, 그 카드는 이번 판에 다시 나오지 않고 다른 카드로 바뀝니다.
- 카드에는 등급 색(일반 회색 / 희귀 파랑 / 전설 금색), 아이콘, 단계(예: 2/5단계), 수치 변화(예: 공격력 30 → 34)가 표시됩니다.
- 카드가 바닥나면 엘릭서·단련·강건이 반복해서 나오므로, 언제나 3장이 나옵니다.

## 일반 / 희귀 카드

| 등급 | 카드 |
|---|---|
| 일반 | 힘, 광분, 신속, 활력, 정밀, 재생, 강철 피부, 영혼 자석, 확장, 질풍 걸음 |
| 희귀 | 흉포, 흡혈, 집중, 다중 사격(마법사·레인저), 관통(마법사·레인저), 그림자 걸음(도적), 맹독(도적·레인저), 가시 갑옷(기사), 참격(기사·도적) |

## 스킬 갈림길 (희귀, 둘 중 하나만)

스킬마다 두 갈래가 있고, 한쪽을 고르면 다른 쪽은 그 판에서 닫힙니다.

| 영웅 | 스킬 | A | B |
|---|---|---|---|
| 베스퍼(도적) | 칼날 폭풍 | 두 번 던지기 | 추적 단검 |
| | 연막 | 질식 연막 (남는 독구름) | 기습 (확정 치명 6회, 은신 중 피해 +50%) |
| | 천 개의 칼날 | 쉼 없는 칼날 (쿨타임 -35%) | 피의 향연 (20회, 타격마다 회복) |
| 아스트라(마법사) | 별의 낙하 | 갈라지는 별 (작은 별 3개) | 불타는 대지 (불 장판) |
| | 중력 우물 | 붕괴 (끝날 때 폭발) | 사건의 지평선 (범위·지속 증가) |
| | 유성우 | 빠른 혜성 (쿨타임 -35%) | 별 폭풍 (유성 24개) |
| 실바(레인저) | 화살 세례 | 연속 사격 | 관통 일제사격 (관통 +3, 둔화) |
| | 도약 사격 | 가시 덫 | 폭발 화살 |
| | 화살비 | 빠른 시위 (쿨타임 -35%) | 폭우 (범위·지속 증가) |
| 레온(기사) | 사자의 포효 | 두 번 울림 | 천둥 포효 (범위 2배) |
| | 방패 돌격 | 파쇄 돌진 (끝날 때 폭발) | 강철 돌진 (더 멀리, 더 세게) |
| | 사자왕의 심판 | 신속한 심판 (쿨타임 -35%) | 왕의 위엄 (범위 증가, 강화 10초) |

## 조합 진화 (전설)

두 카드를 모두 최대 단계로 올리면 다음 레벨업에 반드시 나옵니다.

| 진화 | 조건 | 효과 |
|---|---|---|
| 처형자 | 힘 + 흉포 | 체력 30% 미만 적에게 치명타 2배 |
| 폭풍 발걸음 | 신속 + 질풍 걸음 | 대시가 끝날 때 충격파 |
| 역병 화살 | 맹독 + 관통 | 출혈 중인 적이 죽으면 출혈이 옆으로 퍼짐 |
| 밤의 칼날 | 맹독 + 그림자 걸음 | 대시로 지나간 적에게 큰 출혈, 확정 치명타 충전 |
| 피의 갑주 | 흡혈 + 가시 갑옷 | 반사 피해 2배, 반사량의 30% 회복 |
| 탄막 | 다중 사격 + 광분 | 6번째 공격마다 사방 12발 |
| 대회전 | 참격 + 확장 | 4번째 공격마다 360도 베기, 피해 +50% |

## 보스 보상 (전설)

불굴(한 번 부활), 광전사, 각성(스킬 쿨타임 -25%), 거신, 최상위 포식자, 탐욕의 왕관 중 3장이 나옵니다.
