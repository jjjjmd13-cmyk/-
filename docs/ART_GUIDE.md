# 크림슨 오스 – 그림(스프라이트) 제작 가이드

현재 적용된 그림과 효과, 실제 프레임 크기, 미리보기는 [ART_UPDATE.md](ART_UPDATE.md)를 참고하세요.
아래 표의 크기는 제작 권장값이며, 새 영웅은 384px, 보스는 512px/640px 프레임을 사용합니다.

이 규격대로 PNG 파일을 만들어 정해진 폴더에 넣으면, 게임이 **자동으로 그 그림을 사용**합니다.
그림이 없는 캐릭터·몬스터는 지금처럼 코드로 그린 그림이 나오므로, 하나씩 순서대로 교체해도 됩니다.

---

## 1. 파일 형식 (모든 그림 공통)

| 항목 | 규격 |
|---|---|
| 파일 | **PNG, 투명 배경** |
| 배치 | 한 동작 = 파일 하나. 프레임을 **왼쪽에서 오른쪽으로 한 줄**로 이어 붙임 (여백·간격 없음) |
| 프레임 크기 | **정사각형**. 파일 가로 = 세로 × 프레임 수 (예: 256×256 프레임 6장 → 1536×256) |
| 방향 | 캐릭터는 **오른쪽을 바라보게**. 왼쪽은 게임이 자동으로 뒤집음 |
| 발 위치 | 모든 프레임에서 **발이 가로 정중앙, 아래쪽에서 1/16 높이**에 오도록 고정 (256 프레임이면 아래에서 16px) |
| 게임 속 크기 | 그림의 **절반 크기**로 표시됨 (256px 프레임 → 화면에서 128px) |

> 프레임마다 발 위치가 흔들리면 게임에서 캐릭터가 덜덜 떨려 보입니다. 발 위치 고정이 가장 중요합니다.

## 2. 폴더와 파일 이름

```
assets/sprites/
├─ heroes/<영웅 ID>/    idle.png  run.png  attack.png  (skill.png  dash.png  death.png)
├─ enemies/<몬스터 ID>/ run.png  (idle.png  attack.png)
└─ bosses/<보스 ID>/    idle.png  run.png  cast.png
```

괄호 안은 **선택**입니다. 없으면 비슷한 동작으로 대신 표시됩니다 (예: skill이 없으면 attack, dash가 없으면 run).

## 3. 동작별 규격

### 영웅

| 파일 | 필수 | 프레임 수 | 반복 | 설명 |
|---|---|---|---|---|
| `idle.png` | ✅ | 4~8 | 반복 | 가만히 서서 숨쉬기 |
| `run.png` | ✅ | 6~8 | 반복 | 달리기 |
| `attack.png` | ✅ | 4~8 | 1회 | 기본 공격. **공격 속도에 맞춰 자동으로 빨라지거나 느려짐** |
| `skill.png` | 선택 | 4~8 | 1회 | 스킬 사용 (모든 스킬에 공통으로 사용) |
| `dash.png` | 선택 | 2~4 | 1회 | 대시 (구르기·순간이동 등) |
| `death.png` | 선택 | 6~10 | 1회 | 쓰러짐. 마지막 프레임에서 멈춤 |

- 무기를 휘두르는 **잔상, 화살, 마법 구슬, 폭발 같은 효과는 게임이 따로 그립니다.** 그림에는 몸과 무기 동작만 넣으면 됩니다.
- 조준은 마우스 방향이지만 그림은 좌우로만 뒤집힙니다. 공격 그림은 **정면(오른쪽)으로 휘두르는 동작**이면 충분합니다.

### 일반 몬스터

| 파일 | 필수 | 프레임 수 | 반복 | 설명 |
|---|---|---|---|---|
| `run.png` | ✅ | 4~8 | 반복 | 이동 (박쥐·망령은 날기/떠다니기) |
| `idle.png` | 선택 | 4~6 | 반복 | 대기 |
| `attack.png` | 선택 | 4~8 | 1회 | 거인 돌진 준비, 폭탄 시체 부풀어 오르기, 망령 사라지기/나타나기 때 재생 |

### 보스

| 파일 | 필수 | 프레임 수 | 반복 | 설명 |
|---|---|---|---|---|
| `idle.png` | ✅ | 4~8 | 반복 | 등장 연출 중 |
| `run.png` | ✅ | 6~8 | 반복 | 이동 (마녀는 떠다니기) |
| `cast.png` | 권장 | 6~10 | 반복 | 모든 공격 패턴(내려찍기·돌진·탄막·장판 등) 동안 재생 |

## 4. 게임에 넣는 방법

1. 위 폴더 구조대로 PNG를 넣습니다. 예: `assets/sprites/heroes/knight/run.png`
2. Godot 에디터로 프로젝트를 열면 자동으로 가져오기(import)가 됩니다.
   에디터 없이 명령줄로 하려면: `godot --headless --import`
3. 게임을 실행하면 바로 새 그림으로 나옵니다. 파일이 없거나 규격이 틀린 캐릭터는 기존 그림으로 표시됩니다.
4. 확인용 스크린샷: `godot --fixed-fps 60 --resolution 1920x1080 res://tests/screenshot.tscn -- ./screenshots`

## 5. 제작 팁 (AI 이미지 생성을 쓰는 경우)

- **같은 캐릭터가 프레임마다 똑같이 생겨야** 합니다. 한 장씩 따로 생성하면 얼굴·옷이 바뀌므로, "sprite sheet" 형태로 한 번에 생성하거나 같은 기준 그림(레퍼런스)을 계속 넣어 주세요.
- 생성한 그림은 배경을 지우고, [Aseprite](https://www.aseprite.org/)나 [LibreSprite](https://libresprite.github.io/)(무료) 같은 도트·스프라이트 편집기에서 **프레임 크기와 발 위치를 맞춰** 한 줄로 내보내면 편합니다.
- 화면에서는 절반 크기로 작게 보이므로, 세밀한 무늬보다 **실루엣과 색이 또렷한 그림**이 잘 보입니다. 몬스터 도감 시트의 색감(구울 회녹색, 망령 푸른 반투명, 마녀 진홍, 군주 보라)을 유지하면 게임 속에서도 구분이 잘 됩니다.
- 어두운 바닥 위에서 보이므로, 캐릭터 가장자리에 **어두운 외곽선**이 있으면 훨씬 잘 보입니다.
- 스토어 일러스트와 게임 속 그림의 분위기가 비슷해야 "광고와 다르다"는 평가를 피할 수 있습니다.
