코드는 이미 다 만들어져 있어서, Creator Dashboard에서 등록하고 **ID만 넣으면** 바로 작동해요.

> 로블록스는 게임 패스 아이콘을 **동그랗게 잘라서** 보여주기 때문에, 그림을 가운데에 모아 두었어요.

**가격을 이렇게 정한 이유**
- 시뮬레이터 장르의 게임 패스는 보통 **100~400 R$** 사이예요.
- **자동 발굴**이 제일 많이 팔려요. 손이 편해지는 패스는 인기가 많아서 가장 비싸게 정했어요.
- **수입 2배**는 게임을 꺼도 효과가 있어서 두 번째로 비싸요.
- 가격은 나중에 언제든 바꿀 수 있어요. 처음엔 조금 낮게 시작해서 판매량을 보고 올려도 돼요.
- 로블록스가 판매 금액의 약 30%를 수수료로 가져가요. 예를 들어 299 R$짜리가 팔리면 약 209 R$를 받아요.

## 등록하는 순서

> 먼저 게임을 한 번 **게시**(File → Publish to Roblox)해야 게임 패스를 만들 수 있어요.

1. https://create.roblox.com 에 들어가서 로그인해요.
2. 위쪽 **Creations**를 누르고 → 내 게임(화석 박물관)을 눌러요.
3. 왼쪽 메뉴에서 **Monetization → Passes**를 눌러요.
4. **Create a Pass**를 눌러요.
5. 아이콘 이미지를 올리고, 위의 **이름**과 **설명**을 복사해서 붙여넣은 뒤 **Create Pass**를 눌러요.
6. 만들어진 패스를 누르고 → 왼쪽 **Sales**에서 **Item for Sale**을 켜고, **가격**을 넣고 저장해요.
7. 패스의 **ID 숫자**를 복사해요.
   - 패스 카드의 `⋯` 메뉴 → **Copy Asset ID**를 누르거나,
   - 주소창 링크 안의 긴 숫자를 복사하면 돼요.
8. 5개 모두 1~7번을 반복해요.

> 메뉴 이름이나 위치는 로블록스 업데이트로 조금 바뀔 수 있어요. 비슷한 이름을 찾으면 돼요.

## ID 넣기

`src/shared/Config.luau` 맨 위의 `id = 0` 자리에 복사한 숫자를 넣어요.

```lua
Config.GamePasses = {
	DoubleSpeed = { id = 123456789, ... },   -- ⚡ 발굴 속도 2배
	DoubleLuck = { id = 123456790, ... },    -- 🍀 행운 2배
	DoubleIncome = { id = 123456791, ... },  -- 🏛️ 박물관 수입 2배
	AutoDig = { id = 123456792, ... },       -- 🤖 자동 발굴
	ExtraHelpers = { id = 123456793, ... },  -- 🦖 조수 칸 +2
}
```

(위 숫자는 예시예요. 꼭 내가 만든 패스의 ID를 넣어 주세요.)

**넣는 방법 두 가지**
- **Studio에서 직접**: Explorer 창 → ReplicatedStorage → Shared → **Config**를 더블클릭해서 숫자를 바꾸고 게시해요. 제일 쉬워요.
- **코드 파일에서**: `src/shared/Config.luau`를 고치고 `python3 tools/build_place.py`로 `FossilMuseum.rbxlx`를 다시 만들어요. ID를 알려주시면 제가 넣어 드릴게요.

## 확인하기

1. 게시한 뒤 **실제 게임**에 들어가요. Studio 테스트에서는 구매 창이 테스트용으로만 떠요.
2. 🛒 상점 → 💎 Robux 탭을 열면, ID를 넣은 패스는 "준비 중" 대신 **"구매"** 버튼이 보여요.
3. 직접 사 보면 버튼이 **"보유 중"**으로 바뀌고 바로 효과가 적용돼요. 다시 접속하지 않아도 돼요.
   - 자동 발굴은 "보유 중" 대신 **켜짐/꺼짐** 버튼이 생겨요.
4. 개발자 본인이 자기 게임 패스를 사도 Robux가 나가요 (수수료를 빼고 일부만 돌아와요). 테스트용으로 하나만 사 보는 걸 추천해요.
