# 🦴 화석 박물관 - 모형 목록

게임 안의 모든 모형은 **에셋 없이 코드가 기본 파트(블록, 원기둥, 공)를 조합해서** 만들어요. 그래서 따로 받을 파일은 없지만, 그만큼 생김새가 단순해요.

| 무엇 | 만드는 코드 |
|---|---|
| 땅에서 튀어나오는 뼈 조각 | `src/client/BonePop.luau` |
| 박물관에 전시되는 완성 화석 | `src/server/FossilModel.luau` |
| 맵, 발굴 지역, 박물관 건물, 랭킹 보드 | `src/server/WorldBuilder.luau` |
| 흙더미, 운석, 삽 | `src/server/DigService.luau` |
| NPC 손님 | `src/client/Visitors.luau` |
| 발굴 조수 | `src/client/HelperVisuals.luau` |
| 흙 튀기기, 떠오르는 글자 | `src/client/Effects.luau` |

## 1. 🦴 뼈 조각 (땅에서 튀어나오는 것)

흙더미에서 화석 조각이 나오면 뼈가 땅에서 튀어나와 빙글 돌다가 주운 사람에게 날아가요 (약 1.8초). 조각 이름마다 모양이 달라요.

| 조각 | 모양 |
|---|---|
| **두개골** | 머리뼈 블록 + 아래턱 + 눈구멍 2개 + 이빨 8개 |
| **척추** | 마디 5개가 이어진 원기둥 줄 + 마디마다 위로 솟은 돌기 |
| **갈비뼈** | 가로 등뼈 1개 + 양쪽으로 휘어 내려오는 갈비뼈 3쌍 |
| **몸통** | 둥근 몸통 공 + 갈비뼈 3쌍 |
| **꼬리** | 점점 작아지며 물결치는 뼈 구슬 6개 |
| **날개** | 팔뼈 1개 + 부채처럼 펼쳐진 손가락뼈 4개 |
| **지느러미** | 넓적한 노 모양 판 + 뼈 마디 4개 |
| **다리 / 앞다리 / 뒷다리** | 양 끝이 둥근 뼈다귀 모양 |

### 공룡 종류별 조각 구성

| 뼈대 종류 | 조각 |
|---|---|
| 네 발 (5개) | 두개골, 척추, 갈비뼈, 앞다리, 뒷다리 |
| 두 발 (5개) | 두개골, 척추, 갈비뼈, 다리, 꼬리 |
| 날개 (4개) | 두개골, 몸통, 날개, 다리 |
| 바다 (4개) | 두개골, 척추, 지느러미, 꼬리 |

### 등급별 겉모습

| 등급 | 색과 재질 | 효과 |
|---|---|---|
| 일반 | 상아색 뼈 | 은은한 빛 |
| 고급 | 상아색 뼈 | 빛 + 반짝이 가루 |
| 희귀 | 상아색 뼈 | 빛 + 반짝이 가루 (더 많이) |
| 영웅 | 연보라 뼈 | 빛 + 반짝이 가루 (더 많이) |
| 전설 | 빛나는 황금 | + 하늘로 **빛기둥**, 바닥 빛 고리 |
| 신화 | 분홍 수정(유리) | + 빛기둥, 빛 고리 |
| 우주 | 빛나는 청록색 | + 빛기둥, 빛 고리 |

- 등급이 높을수록 뼈 크기가 커지고 더 빨리 돌아요.
- 주운 사람 화면에만 이름표("[희귀] 트리케라톱스 · 두개골")가 뜨고, 처음 얻은 조각이면 "✨ NEW! ✨"가 붙어요.
- 날아와서 닿는 순간 반짝 터져요.
- 다른 사람의 뼈 조각도 120스터드 안에서 보이고, 빛기둥은 멀리서도 보여요.

## 3. 🗺️ 맵

**전체**: 모래 땅(1100×1100 스터드), 맑은 오후 조명

### 🏜️ 사막 발굴장 (가운데, 처음부터 열림)
- 갈색 흙바닥
- 나무 울타리와 기둥 (10스터드마다)
- 흙더미 100개 (10×10)
- 발굴장 간판

### 🧊 빙하 / 🌋 화산 / 🌊 해안 (바깥쪽, 코인으로 열기)

| 지역 | 바닥 | 흙더미 | 장식 |
|---|---|---|---|
| 🧊 빙하 지대 | 눈 | 빙하 재질 64개 | 얼음 기둥 14개 |
| 🌋 화산 지대 | 현무암 | 갈라진 용암 재질 64개 | 용암 웅덩이 7개, 바위 10개, 불 뿜는 분화구 |
| 🌊 해안 절벽 | 모래 | 석회암 재질 64개 | 바다(물 판), 야자수 8그루 |

- 지역마다 이름 간판이 있어요.
- 잠긴 지역에는 **포스필드 벽 4면**과 "🔒 지역 이름 · 💰 가격" 글씨가 있어요. 연 사람 화면에서는 벽이 사라지고 지나갈 수 있어요.
- 사막에서 각 지역까지 **돌길**이 이어져요. 지역 입구 쪽에는 장식을 두지 않아서 길이 막히지 않아요.

### 흙더미 종류

| 종류 | 모양 | 생기는 확률 |
|---|---|---|
| 흙더미 | 지역 색의 둥근 언덕. 팔수록 낮아지고, 부서진 뒤 12초 후 다시 솟아나요 | 92% |
| ✨ 반짝이는 흙더미 | 금빛이 섞이고 반짝이와 빛이 나요 | 8% |
| ☄️ 운석 | 보라색 돌덩이 + 보라/파랑 불꽃 + 반짝이. 하늘에서 떨어져 폭발 효과와 함께 착지해요 | 운석 이벤트 때 지역마다 6개 |

### 시작 지점 주변
- 시작 지점 (돌 바닥, 발굴장 쪽을 바라봄)
- 양옆에 **랭킹 보드 2개**: 🏆 완성 화석 랭킹, ❤️ 이번 주 좋아요 랭킹 (나무판 + 다리 2개)

### 박물관
- **12개**가 사막을 둘러싼 원 모양으로 놓여 있어요 (반지름 150스터드).
- 입구가 모두 사막을 향하고, 각각 사막으로 이어지는 돌길이 있어요.

## 4. 🏛️ 박물관 안

| 무엇 | 설명 |
|---|---|
| 바닥 | 대리석 (48×48 스터드) |
| 벽 | 뒷벽(높음) + 양옆 벽(낮음). 앞쪽은 열려 있음 |
| 입구 | 대리석 원기둥 4개 + 위에 가로 들보 |
| 간판 | 입구 위 나무 간판 "OO의 박물관" (비어 있으면 "빈 박물관") |
| 좋아요 받침대 | 입구 왼쪽 앞 분홍 대리석 기둥. "❤️ 사람 좋아요 / 🧑 손님 좋아요" 표시. 가까이 가서 꾹 누르면 좋아요 |
| 전시대 16개 | 4×4 대리석 받침대. 화석이 있으면 **등급 색**, 비어 있으면 회색, 아직 안 연 칸은 반투명 |
| 전시 화석 | 수입이 높은 화석부터 자동으로 올라가요 (위 2번의 3D 뼈대) |
| 🧑 NPC 손님 | 1~6명 (전시가 화려할수록 많아짐) |

### 🧑 NPC 손님 모양
- 다리 2개, 몸통, 팔 2개, 둥근 머리
- 옷 색 7가지, 피부색 4가지, 바지 색 랜덤
- 40% 확률로 모자
- 걸을 때 다리를 흔들고 몸이 살짝 들썩여요
- 화석 앞에서 2~6초 멈춰 구경해요
- 가끔 머리 위에 ❤️가 떠올라요 (손님 좋아요)

## 💡 앞으로 바꾸면 좋은 점

지금 모형은 기본 파트로 만든 거라 **레고 같은 단순한 느낌**이에요. 특히 완성 화석 뼈대는 진짜 공룡 화석보다 막대기를 이어 붙인 느낌에 가까워요.
출시 후 반응이 좋으면 Creator Store의 무료 공룡 뼈 모형이나 Blender로 만든 모형으로 바꾸는 걸 추천해요.
