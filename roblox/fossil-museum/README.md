# 🦴 화석 박물관 (Fossil Museum) - 로블록스 게임

땅을 파서 공룡 화석 조각을 모으고, 다 모은 화석을 조립해서 **내 박물관**에 전시하는 게임이에요.
전시한 화석은 관람객 수입(코인)을 계속 벌어 주고, 다른 플레이어가 내 박물관에 **좋아요**를 누르면 수입이 더 늘어나요.

## 게임 흐름

1. **사막 발굴장**에서 삽으로 흙더미를 파요. 클릭하거나 누르고 있으면 계속 파져요.
2. 흙더미가 부서지면 코인과 **화석 조각**이 나와요. 반짝이는 흙더미는 조각이 꼭 나오고 희귀한 게 잘 나와요. 조각이 나오면 **뼈가 땅에서 튀어나와** 빙글 돌다가 내게 날아와요. 조각 모양(두개골, 척추, 다리…)이 다 다르고, 전설 이상은 하늘로 **빛기둥**이 솟아서 주변 사람도 볼 수 있어요.
3. 한 종류의 조각(두개골, 척추, 다리 등)을 다 모으면 📖 **도감**에서 **조립**해요.
4. 조립한 화석은 내 박물관에 **3D 뼈대 모형**으로 자동 전시되고, 초당 코인을 벌어요. 전시가 화려할수록 🧑 **NPC 손님**이 많이 와서 구경하고 가끔 좋아요를 남겨요.
   - 사람 좋아요는 100개까지 1개당 수입 +1%, 그 뒤로는 +0.2%씩 한도 없이 올라요. NPC 손님 좋아요는 사람 좋아요의 0.2개로 쳐요.
   - 좋아요를 **누른 사람**도 코인 보상을 받아요 (같은 박물관은 하루 한 번).
   - 랭킹 보드는 **모든 서버 통합** 랭킹이고, 좋아요 랭킹에는 사람 좋아요만 들어가요.
5. 🛒 **상점**에서 더 좋은 삽을 사고 전시대를 늘려요. 🦖 **발굴 조수**를 고용하면 옆에서 알아서 흙더미를 파요.
6. 🗺️ **새 지역**(빙하 → 화산 → 해안)을 열면 그 지역에서만 나오는 화석이 있고, 수입이 훨씬 커요.
7. 코인이 충분히 모이면 🔁 **환생**해요. 코인, 도구, 지역은 초기화되지만 수입·코인·행운이 영구적으로 올라가요.
8. 🤝 **같이 파기**: 여러 명이 같은 흙더미를 파면 각자 판 만큼(깎은 체력 비율) 코인과 조각 확률을 나눠 받고, 2명 이상이면 보상이 **+20%** 늘어나요. 마지막 한 방만 노리면 거의 못 받아요.
9. 매일 📜 **퀘스트** 3개와 🎁 **접속 보상**(7일 주기)을 받고, 🤝 **거래**로 친구와 조각을 바꿔요.
10. 8분마다 ☄️ **운석 낙하 이벤트**가 2분 동안 모든 지역에서 열려요. 운석에서만 **우주 등급** 화석이 나와요.
11. 게임을 꺼도 박물관은 계속 벌어요. 다시 접속하면 최대 3시간 동안 번 수입의 50%를 받아요.

| 내용 | 수량 |
|---|---|
| 발굴 지역 | 4곳 (사막, 빙하, 화산, 해안). 멀수록 수입 x6 / x40 / x250 |
| 화석 종류 | 52종 (지역별 11~14종, 운석 이벤트 4종), 7등급 |
| 발굴 도구 | 9개 (나무 삽부터 블랙홀 드릴까지) |
| 발굴 조수 | 6종, 기본 3마리까지 데리고 다님 |
| 박물관 전시대 | 최대 16칸, 박물관 부지 12개 (서버 최대 12명) |
| 성장 요소 | 환생, 지역 완성 보너스, 좋아요 보너스, 매일 보상, 일일 퀘스트 |
| 소셜 | 박물관 좋아요, 플레이어 거래, 랭킹 보드 2개(완성 화석, 이번 주 좋아요) |
| 수익화 | 게임 패스 5개, 개발자 상품 5개 |

## 바로 열어보기 (가장 쉬운 방법)

1. 이 폴더의 **`FossilMuseum.rbxlx`** 파일을 PC로 내려받아요. GitHub에서 파일을 연 뒤 "Download raw file" 버튼을 누르면 돼요.
2. 파일을 더블클릭하면 Roblox Studio에서 열려요.
3. 위쪽의 **▶ Play** 버튼을 눌러 테스트해요.

맵(발굴 지역 4곳, 박물관 8개, 길, 랭킹 보드)은 게임이 시작될 때 스크립트가 자동으로 만들어요. 그래서 처음 열었을 때 화면이 비어 있는 게 정상이에요.

> **저장 기능 켜기**: Studio에서 테스트할 때 데이터를 저장하려면, 먼저 게임을 게시(File → Publish to Roblox)해야 해요.
> 그다음 Game Settings → Security → **Enable Studio Access to API Services**를 켜세요. 켜지 않으면 임시 데이터로 플레이돼요.

## Rojo로 작업하기 (코드를 계속 고칠 때 추천)

```bash
rokit install            # rojo, selene, stylua 설치 (rokit.toml)
rojo serve               # 그다음 Studio의 Rojo 플러그인에서 Connect
# 또는 파일로 만들기
rojo build -o FossilMuseum.rbxlx
```

Rojo가 없다면 `python3 tools/build_place.py`로도 `FossilMuseum.rbxlx`를 다시 만들 수 있어요.

## 파일 구조

```
src/
  shared/   (ReplicatedStorage.Shared - 서버와 클라이언트가 같이 씀)
    Config.luau             ← 가격, 확률, 수입, 화석·지역·조수·퀘스트 목록 등 모든 숫자
    Economy.luau            ← 뽑기 확률, 수입·행운·환생 가격 계산
    Util.luau               ← 숫자 표시 (1.2K, 3.4M)
  server/   (ServerScriptService.Server)
    Main.server.luau        ← 서버 시작점
    WorldBuilder.luau       ← 맵 자동 생성 (지역 4곳, 잠금 벽, 장식, 박물관, 랭킹 보드)
    DataService.luau        ← 저장 / 불러오기 (DataStore)
    Zones.luau              ← 위치로 지역 찾기, 잠금 확인
    DigService.luau         ← 흙더미, 삽질, 운석 이벤트, 도구 지급
    Rewards.luau            ← 흙더미 보상 (삽질·조수 공통)
    HelperService.luau      ← 발굴 조수 자동 발굴
    MuseumService.luau      ← 박물관 배정, 전시, 수입, 좋아요, 조립/판매, 이동
    FossilModel.luau        ← 3D 뼈대 모형 생성 (파트로 만들어서 에셋 필요 없음)
    ShopService.luau        ← 도구·전시대·지역·조수 구매, 환생, Robux 결제
    QuestService.luau       ← 일일 퀘스트, 매일 접속 보상
    TradeService.luau       ← 플레이어 거래
    LeaderboardService.luau ← 랭킹 보드 (OrderedDataStore)
    Passes.luau             ← 게임 패스 확인
    Net.luau                ← 클라이언트 통신
  client/   (StarterPlayerScripts.Client)
    Main.client.luau        ← 클라이언트 시작점, 효과음
    Hud.luau                ← 코인, 이벤트 배너, 메뉴 버튼 8개, 알림, 예/아니오 창
    PanelManager.luau       ← 창 열기/닫기
    PanelKit.luau           ← 창 공통 부품
    Panels/                 ← 도감, 상점, 지역, 조수, 퀘스트, 환생, 거래 창
    Digger.luau             ← 삽질 입력 (PC 클릭, 모바일 터치, 자동 발굴)
    Barriers.luau           ← 잠긴 지역 벽 (내 화면에서만 막힘)
    HelperVisuals.luau      ← 조수 모형이 플레이어를 따라다님
    Effects.luau            ← 흙 튀기기, +코인 연출
    Visitors.luau           ← 박물관 NPC 손님, 하트 연출
    BonePop.luau            ← 뼈 조각이 튀어나와 날아오는 연출, 빛기둥
```

## 게시 전에 꼭 할 일

1. **최대 인원 12명**: Game Settings → Places → Max Players를 12로 설정해요. 박물관 부지가 12개예요 (`Config.PlotCount`).
   - 친구랑만 하고 싶다면 Creator Dashboard → Monetization → **Private Servers**를 켜세요. 무료 또는 Robux 월 구독으로 정할 수 있어요.
2. **게임 패스와 개발자 상품 만들기**: Creator Dashboard → 내 게임 → Monetization → Passes / Developer Products에서 만들어요.
   - 게임 패스: ⚡ 발굴 속도 2배, 🍀 행운 2배, 🏛️ 박물관 수입 2배, 🤖 자동 발굴, 🦖 조수 칸 +2
   - 개발자 상품: 코인 주머니, 코인 상자, 코인 금고, 행운 부스트 15분, 🌟 서버 전체 행운 2배 15분
   - 만든 ID를 `src/shared/Config.luau` 맨 위의 `id = 0` 자리에 넣어요. ID가 0이면 상점에 "준비 중"으로 표시돼요.
3. **썸네일과 아이콘**: 박물관에 전설 화석이 빛나는 장면을 캡처해서 쓰면 좋아요.

## 밸런스 조정

`Config.luau`의 숫자만 바꾸면 돼요.

| 바꾸고 싶은 것 | 고칠 항목 |
|---|---|
| 희귀한 화석이 나오는 확률 | `Rarities`의 `weight` |
| 화석 1개당 초당 수입 | `Rarities`의 `income` |
| 삽 가격과 성능 | `Tools` |
| 전시대 확장 가격 | `SlotPrices` |
| 같이 파기 보너스 | `CoopBonus` |
| 좋아요 보너스, NPC 손님 좋아요 빈도, 좋아요 누른 사람 보상 | `LikeBonus`, `LikeSoftCap`, `NpcLikeWeight`, `NpcLikeAppealDivisor`, `LikerReward...` |
| 운석 이벤트 간격과 지속시간 | `MeteorInterval`, `MeteorDuration` |
| 지역 가격과 배수 | `Zones`의 `price`, `incomeMult`, `coinMult`, `hpMult` |
| 환생 가격과 보너스 | `Rebirth` |
| 조수 가격과 속도 | `Helpers` |
| 퀘스트 목표와 보상 | `QuestTemplates`, `QuestRewardSeconds` |

확률을 시뮬레이션해 보면 나무 삽으로 첫 화석을 완성하는 데 약 2~3분 걸려요. 처음에 빨리 재미를 느끼도록 맞춘 값이에요.

## 참고

- 이 코드는 클라우드 환경에서 작성해서 **Studio에서 아직 실행해 보지 않았어요**. Play를 눌렀을 때 Output 창에 빨간 오류가 나오면 그 메시지를 그대로 알려주세요. 바로 고칠게요.
- 잠긴 지역의 벽은 각 플레이어 화면에서만 단단해지고, 서버도 잠긴 지역의 흙더미와 이동을 막아요.
- 거래는 내용이 바뀌면 '준비'가 풀리고, 바뀐 뒤 3초 동안은 준비를 누를 수 없어서 막판 바꿔치기를 막아요.
- 데이터 저장은 기본적인 재시도와 자동 저장(2분마다), 서버 종료 시 저장을 지원해요. 접속자가 많아지면 ProfileStore 같은 세션 잠금 방식으로 바꾸는 걸 추천해요.
